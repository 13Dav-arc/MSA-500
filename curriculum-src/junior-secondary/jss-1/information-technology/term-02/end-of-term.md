## Quiz

### Q1 [single-choice]
Stem: What are the three essential pillars that collaboratively comprise a complete, functional computer system?
A) Hardware, Software, and Peopleware (correct)
B) Monitor, Keyboard, and Mouse
C) Motherboard, Processor, and RAM
D) Electricity, Voltage, and Inverter
Feedback: A complete computer system requires physical machinery (Hardware), logical instructions (Software), and human users (Peopleware) working in mutual interdependence.

### Q2 [single-choice]
Stem: What is the defining characteristic of computer hardware?
A) It consists of the tangible, physical components of a computer that can be seen, touched, and physically handled (correct)
B) It represents the invisible program instructions stored in memory
C) It refers to the certified human technicians who administer networks
D) It is the digital operating manual supplied with computer software
Feedback: Hardware comprises all physical, tangible, and electro-mechanical parts of the computer system that can be physically touched.

### Q3 [single-choice]
Stem: What category of the computer system consists of non-tangible programs, procedures, and instructions that direct the hardware?
A) Software (correct)
B) Hardware
C) Peopleware
D) System Unit
Feedback: Software represents the non-tangible, logical sets of programs that instruct hardware on how to execute computational tasks.

### Q4 [single-choice]
Stem: Why is peopleware (humanware) considered an indispensable component of any computer system?
A) Computers have no autonomous will or independent consciousness and depend completely on human direction to define goals and process data (correct)
B) The Central Processing Unit will not conduct electricity unless a human physically holds it
C) Computer software cannot be displayed on a screen without a human blowing on the glass
D) Computers cannot connect to electrical sockets without human hands
Feedback: Computers are automated tools with no independent mind; they require human peopleware to create programs, enter data, and act upon output.

### Q5 [single-choice]
Stem: What foundational computing principle asserts that hardware, software, and peopleware must work collaboratively, such that the absence of one cripples the entire system?
A) Mutual interdependence (correct)
B) Hardware obsolescence
C) Binary opposition
D) Data virtualization
Feedback: Mutual interdependence states that hardware cannot function without software, software cannot run without hardware, and neither produces value without peopleware.

### Q6 [single-choice]
Stem: What is the primary difference between the System Unit and the Central Processing Unit (CPU)?
A) The System Unit is the large protective casing, while the CPU is the microscopic processor chip mounted on the motherboard inside (correct)
B) The System Unit displays graphics, while the CPU types letters
C) The System Unit is software, while the CPU is peopleware
D) The System Unit is portable, while the CPU is permanently bolted to the floor
Feedback: The System Unit is the protective external chassis; the CPU is the miniature silicon microprocessor mounted inside on the motherboard.

### Q7 [single-choice]
Stem: Which subunit inside the CPU acts as the supervisor, directing data flow and decoding instructions without executing mathematical calculations?
A) Control Unit (CU) (correct)
B) Arithmetic Logic Unit (ALU)
C) Accumulator Register
D) Power Supply Unit
Feedback: The Control Unit (CU) coordinates and manages all computer operations, fetching and decoding instructions without performing arithmetic calculations.

### Q8 [single-choice]
Stem: Which subunit of the CPU is specifically responsible for executing mathematical calculations (addition, subtraction) and logical comparisons?
A) Arithmetic Logic Unit (ALU) (correct)
B) Control Unit (CU)
C) Program Counter
D) System Clock
Feedback: The Arithmetic Logic Unit (ALU) carries out all arithmetic operations ($+, -, \times, \div$) and evaluations of logical conditions ($=, >, <$).

### Q9 [single-choice]
Stem: What are the four stages of the CPU Machine Cycle in correct chronological order?
A) Fetch -> Decode -> Execute -> Store (correct)
B) Execute -> Store -> Fetch -> Decode
C) Decode -> Fetch -> Store -> Execute
D) Store -> Decode -> Execute -> Fetch
Feedback: The CPU processes every instruction through four continuous stages: Fetch (retrieve), Decode (interpret), Execute (perform), and Store (save result).

### Q10 [single-choice]
Stem: What are the microscopic, ultra-high-speed temporary storage cells located directly inside the CPU called?
A) Registers (correct)
B) Solid-State Drives
C) Optical Discs
D) Magnetic Platters
Feedback: Registers are high-speed internal memory cells located directly inside the CPU that hold immediate data, instructions, and memory addresses.

### Q11 [single-choice]
Stem: What unit of frequency measurement is universally used to rate the clock speed of modern computer processors?
A) Gigahertz (GHz) (correct)
B) Revolutions per minute (RPM)
C) Kilowatt-hours (kWh)
D) Pages per minute (PPM)
Feedback: Modern processor clock speeds are rated in Gigahertz (GHz), representing billions of clock pulses and machine cycle ticks per second.

### Q12 [single-choice]
Stem: What is the standard international layout of alphabetic keys on an English computer keyboard called?
A) QWERTY layout (correct)
B) DVORAK layout
C) ALPHABETIC layout
D) NUMERIC layout
Feedback: English computer keyboards follow the standard QWERTY layout, named after the first six letters on the top alphabetic row.

### Q13 [single-choice]
Stem: What is the operational distinction between the Backspace key and the Delete key on a computer keyboard?
A) Backspace deletes text to the left of the cursor, while Delete removes text to the right of the cursor (correct)
B) Backspace deletes entire paragraphs, while Delete removes single letters
C) Backspace operates only on numbers, while Delete operates only on punctuation
D) Backspace shuts down the computer, while Delete restarts the monitor
Feedback: `Backspace` erases characters immediately to the left of the cursor, while `Delete` erases characters immediately to the right.

### Q14 [single-choice]
Stem: How does a modern optical computer mouse detect two-dimensional movement across a desktop surface?
A) By using a Light Emitting Diode (LED) or laser sensor to track surface light reflections (correct)
B) By rolling a rubber ball against mechanical wheel encoders
C) By measuring acoustic sound pressure waves bouncing off the mouse pad
D) By detecting thermal body heat from the user's palm
Feedback: Optical mice use an LED or laser beam and an optical sensor to track movement across a flat surface with high precision.

### Q15 [single-choice]

A) Optical flatbed scanner (correct)
B) Laser printer
C) Visual Display Unit

### Q16 [single-choice]

B) They automatically manufacture new merchandise on the shelves

### Q17 [single-choice]
Stem: What is the key difference between soft copy output and hard copy output?
A) Soft copy is intangible digital output on screens or speakers, while hard copy is permanent physical output on paper (correct)
B) Soft copy requires a printer, while hard copy requires audio speakers
C) Soft copy cannot be edited, while hard copy can be updated instantaneously on a screen
D) Soft copy lasts forever, while hard copy vanishes when electrical power is disconnected
Feedback: Soft copy is intangible and transient (monitors, audio), while hard copy is tangible and permanent (printed paper, plotted drawings).

### Q18 [single-choice]

C) Dot matrix display

### Q19 [single-choice]

B) It prints high-resolution color photographs faster than any other printer

### Q20 [single-choice]
Stem: What printing technology is utilized in high-speed office laser printers to produce sharp, smudge-proof pages?

### Q21 [single-choice]

A) Plotter (correct)
B) Dot matrix printer
C) Visual Display Unit
D) Multimedia projector

### Q22 [single-choice]
Stem: What compact, silent printing technology is universally utilized inside bank ATMs and supermarket POS terminals using heat-sensitive paper?
A) Thermal printing (correct)
B) Laser printing
C) Dot matrix impact printing
D) Pen plotter printing
Feedback: Thermal printers apply heat directly to chemically treated paper to produce rapid, silent receipts without ribbons or ink cartridges.

### Q23 [single-choice]
Stem: What is the primary operational characteristic of Random Access Memory (RAM)?
A) It is volatile working memory that temporarily holds open applications and active data, losing its contents when power is turned off (correct)
B) It is non-volatile permanent memory containing factory startup instructions
C) It stores music files and photos permanently when the computer is shut down
D) It converts alternating electrical current into direct current
Feedback: RAM is volatile working memory; it holds currently open programs and active data, and its contents disappear when power is cut.

### Q24 [single-choice]
Stem: What critical computer startup firmware is permanently stored inside the non-volatile Read-Only Memory (ROM) chip?
A) The BIOS (Basic Input/Output System) and Bootstrap Loader (correct)
B) The Microsoft Word application program
C) The Google Chrome browser cache
D) The Antivirus virus definition database
Feedback: ROM stores the BIOS firmware, which performs the Power-On Self-Test (POST) and loads the operating system when the computer is powered on.

### Q25 [single-choice]
Stem: What major structural advantage do Solid-State Drives (SSDs) possess over traditional mechanical Hard Disk Drives (HDDs)?
A) SSDs use electronic flash memory chips with zero moving parts, making them faster, silent, and shock-resistant (correct)
B) SSDs use heavy spinning magnetic platters that store data optically
C) SSDs rely on glass vacuum tubes to amplify data signals
D) SSDs require continuous electrical battery current to keep files saved
Feedback: SSDs record data electronically on solid flash memory chips with no moving mechanical parts, providing silent, durable, and ultra-fast storage.

### Q26 [single-choice]

A) 1,024 MB (correct)

### Q29 [single-choice]

### Q33 [single-choice]

### Q37 [true-false]

A) True (correct)
B) False

### Q38 [true-false]

### Q39 [true-false]
Stem: A smartphone touchscreen functions simultaneously as an output display device and an input tactile sensor.
A) True (correct)

### Q40 [true-false]
Stem: In proper workstation ergonomics, a user's wrists should be bent sharply backwards at a 90-degree angle while typing on a keyboard.
A) True
B) False (correct)
Feedback: Wrists should be kept straight and neutral, forming a horizontal line with the forearms; bending wrists sharply pinches nerves and causes CTS.
