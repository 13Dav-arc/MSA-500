## Quiz

### Q1 [single-choice]
Stem: What are the three foundational pillars that collaboratively make up a complete, functional computer system?
A) Hardware, Software, and Peopleware (correct)
B) Monitors, Keyboards, and Mouse controllers
C) Electricity, Internet, and Wi-Fi antennas
D) Inks, Toners, and Printing papers
Feedback: A complete computer system requires physical machinery (Hardware), logical program instructions (Software), and human operators (Peopleware) working in mutual interdependence.

### Q2 [single-choice]
Stem: What is the fundamental distinction between computer hardware and computer software?
A) Hardware is physical and tangible, while software consists of non-tangible program instructions (correct)
B) Hardware is stored on paper, while software is manufactured from silicon
C) Hardware cannot fail, while software wears out mechanically
D) Hardware is used only in banks, while software is used only in schools
Feedback: Hardware comprises the physical, tangible machinery that can be seen and handled, whereas software consists of intangible, logical programs that instruct the hardware.

### Q3 [single-choice]
Stem: Why is peopleware (humanware) considered an indispensable part of any computer system?
A) Computers possess no autonomous purpose or independent mind and require human direction to define tasks and process data (correct)
B) Software programs cannot execute unless a human physically blows air onto the motherboard
C) The Central Processing Unit only operates when touched by human skin
D) Computer networks cannot transmit electricity without human cables
Feedback: Peopleware is vital because computers are automated tools that rely entirely on human beings to author programs, enter data, manage networks, and interpret results.

### Q4 [single-choice]
Stem: What principle states that computer hardware, software, and peopleware rely completely on each other so that the absence of one cripples the system?
A) Mutual interdependence (correct)
B) Data redundancy
C) Hardware obsolescence
D) Binary automation
Feedback: Mutual interdependence emphasizes that hardware cannot work without software, software cannot run without hardware, and neither produces value without peopleware.

### Q5 [single-choice]
Stem: What is the primary protective rectangular enclosure that houses the motherboard, power supply, CPU, and internal drives called?
A) The System Unit (correct)
B) The Central Processing Unit
C) The Visual Display Unit
D) The Peripheral Chassis
Feedback: The System Unit is the main metal or plastic casing housing the primary internal electronic components of a computer.

### Q6 [single-choice]
Stem: Which subunit of the CPU directs the flow of data, decodes instructions, and coordinates operations like a traffic director without calculating numbers?
A) Control Unit (CU) (correct)
B) Arithmetic Logic Unit (ALU)
C) Accumulator Register
D) Power Supply Unit
Feedback: The Control Unit (CU) supervises, fetches, decodes, and directs instructions throughout the computer system, but it does not execute arithmetic.

### Q7 [single-choice]
Stem: Which subunit inside the CPU performs all mathematical calculations (addition, subtraction) and logical comparisons?
A) Arithmetic Logic Unit (ALU) (correct)
B) Control Unit (CU)
C) Program Counter
D) System Clock
Feedback: The Arithmetic Logic Unit (ALU) carries out all arithmetic operations ($+, -, \times, \div$) and evaluations of logical conditions.

### Q8 [single-choice]
Stem: What is the correct chronological sequence of steps in the CPU Machine Cycle?
A) Fetch -> Decode -> Execute -> Store (correct)
B) Execute -> Store -> Fetch -> Decode
C) Decode -> Fetch -> Store -> Execute
D) Store -> Decode -> Execute -> Fetch
Feedback: The CPU processes every instruction by cycling through four steps: Fetch (retrieve), Decode (translate), Execute (calculate), and Store (save result).

### Q9 [single-choice]
Stem: What are the microscopic, ultra-high-speed temporary memory locations located directly inside the CPU called?
A) Registers (correct)
B) Flash memory drives
C) Optical discs
D) Hard drive platters
Feedback: Registers are high-speed internal memory cells inside the CPU that hold immediate instructions, addresses, and data during active execution.

### Q10 [single-choice]
Stem: What is the operational difference between the Backspace key and the Delete key on a standard QWERTY keyboard?
A) Backspace deletes text to the left of the cursor, while Delete removes text to the right of the cursor (correct)
B) Backspace deletes entire paragraphs, while Delete removes single characters
C) Backspace operates only on numbers, while Delete operates only on alphabet letters
D) Backspace shuts down the computer, while Delete restarts the monitor
Feedback: `Backspace` erases the character immediately to the left of the cursor, while `Delete` erases the character immediately to the right.

### Q11 [single-choice]
Stem: How does a modern optical mouse detect movement across a desktop surface?
A) By using a Light Emitting Diode (LED) or laser sensor to track surface light reflections (correct)
B) By rolling a heavy rubber ball against mechanical wheel encoders
C) By measuring acoustic sound waves bouncing off the mouse pad
D) By detecting body heat from the user's palm
Feedback: Optical mice use an LED or laser sensor to capture microscopic surface images, calculating movement coordinates electronically.

### Q12 [single-choice]
Stem: Why are optical barcode readers used at retail supermarket checkouts instead of having cashiers type prices manually?
A) They provide instantaneous, automated data entry that eliminates human typing errors (correct)
B) They automatically manufacture new products on the store shelves
C) They calculate government taxes without connecting to a computer database
D) They convert paper currency into digital cryptocurrency
Feedback: Barcode readers automate data entry directly from product packaging, speeding up customer checkout and eliminating manual typing errors (GIGO).

### Q13 [single-choice]
Stem: What is the key difference between soft copy output and hard copy output?
A) Soft copy is intangible digital output on screens, while hard copy is permanent physical output on paper (correct)
B) Soft copy requires a printer, while hard copy requires audio speakers
C) Soft copy cannot be edited, while hard copy can be updated instantaneously on a screen
D) Soft copy lasts forever, while hard copy vanishes when electrical power is disconnected
Feedback: Soft copy is intangible and transient (monitors, audio), while hard copy is tangible and permanent (printed paper, plotted drawings).

### Q14 [single-choice]
Stem: What unique capability makes the Dot Matrix impact printer indispensable in banking and warehouse administration?
A) Its mechanical physical strike can print through multipart carbon continuous paper to produce duplicate copies (correct)
B) It prints high-resolution color photographs faster than any other printer
C) It operates in complete, noiseless silence
D) It uses laser light beams and heat-fused powdered toner
Feedback: The physical pin impact of a dot matrix printer is the only technology that can press through multipart carbon forms to produce simultaneous duplicate copies.

### Q15 [true-false]
Stem: Laser printers use microscopic sprays of liquid ink droplets ejected from heated nozzles to form letters on paper.
A) True
B) False (correct)
Feedback: Laser printers use dry powdered plastic toner fused to paper with heat; liquid ink droplets are used exclusively by Inkjet printers.

### Q16 [true-false]
Stem: A smartphone touchscreen functions simultaneously as an output display device and an input tactile sensor.
A) True (correct)
B) False
Feedback: Touchscreens are hybrid peripherals that display visual output while detecting user finger taps and gestures as input.

### Q17 [multi-select]
Stem: Which of the following components are physically housed inside a standard computer System Unit? (Select all that apply)
A) Motherboard (System Board) (correct)
B) Central Processing Unit (CPU) (correct)
C) Power Supply Unit (PSU) (correct)
D) Multimedia Data Projector
Feedback: The motherboard, CPU, and power supply unit are located inside the System Unit. A data projector is an external output peripheral.

### Q18 [multi-select]
Stem: Which two of the following printers belong to the Non-Impact printer category? (Select two)
A) Inkjet printer (correct)
B) Laser printer (correct)
C) Dot matrix printer
D) Daisy wheel printer
Feedback: Inkjet and Laser printers form images without striking the paper mechanically, classifying them as non-impact printers.

### Q19 [matching]
Stem: Match each computer hardware item to its primary system role:
Clue: Central Processing Unit -> Interprets and executes program instructions as the computational engine
Clue: QWERTY Keyboard -> Captures alphanumeric text and keystroke commands as an input device
Clue: Laser Printer -> Produces high-speed, permanent physical hard copies using toner
Clue: Motherboard -> Connects and allows communication between all internal components
Feedback: CPU executes instructions; Keyboard inputs text; Laser printer prints hard copies; Motherboard connects components.

### Q20 [matching]
Stem: Match each CPU subunit or cycle stage to its operational function:
Clue: Control Unit -> Manages data flow and translates program instructions like a traffic supervisor
Clue: Arithmetic Logic Unit -> Executes mathematical arithmetic and evaluates logical comparisons
Clue: Fetch -> Retrieves an instruction from memory (RAM) and places it into an internal register
Clue: Accumulator -> Temporarily holds intermediate mathematical results calculated by the ALU
Feedback: CU directs data flow; ALU calculates and compares; Fetch retrieves instructions; Accumulator holds intermediate calculation results.
