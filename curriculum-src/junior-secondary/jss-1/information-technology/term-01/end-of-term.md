## Quiz

### Q1 [single-choice]
Stem: What is an electronic computer fundamentally defined as in information technology?
A) An electronic device that accepts data as input, processes it according to stored instructions, stores results, and produces meaningful information as output (correct)
B) An electric appliance designed exclusively to transmit television broadcast signals
C) A mechanical typewriter that imprints alphanumeric characters onto paper rolls
D) A decorative screen used only to display digital video advertisements
Feedback: A computer is an electronic machine that accepts raw data, processes it through algorithmic instructions, stores data in memory, and outputs actionable information.

### Q2 [single-choice]
Stem: What is the primary difference between raw data and processed information?
A) Data consists of unorganized, raw facts without context, while information is structured, meaningful, and useful for decision-making (correct)
B) Data can only be viewed on a mobile phone, while information is printed only in newspapers
C) Data is always accurate, while information is always misleading
D) Data cannot be stored in electronic memory, while information requires no hardware
Feedback: Data refers to isolated, unprocessed facts and figures (e.g., test scores like 45, 82). Information is data that has been processed into a meaningful structure (e.g., student report cards).

### Q3 [single-choice]
Stem: What is the correct chronological sequence of the Information Processing Cycle in all computer systems?
A) Input -> Processing -> Output -> Storage (correct)
B) Storage -> Input -> Processing -> Output
C) Output -> Processing -> Storage -> Input
D) Processing -> Output -> Input -> Storage
Feedback: The standard computer Information Processing Cycle (IPOS) moves strictly through four stages: Input (data capture), Processing (CPU manipulation), Output (result presentation), and Storage (memory preservation).

### Q4 [single-choice]
Stem: What does the computing acronym "GIGO" stand for?
A) Garbage In, Garbage Out (correct)
B) General Input, General Output
C) Global Internet, Global Operation
D) Graphical Interface, Graphical Output
Feedback: GIGO (Garbage In, Garbage Out) highlights that if incorrect or corrupt data is input into a computer, the resulting output will inevitably be inaccurate.

### Q5 [single-choice]

### Q9 [single-choice]

### Q10 [single-choice]

### Q12 [single-choice]

### Q13 [single-choice]

### Q15 [single-choice]
