## Quiz

### Q1 [single-choice]
Stem: Making a sensible guess of nearly correct distances, weights, prices, or capacities without actual measurements is called:
A) Estimation (correct)
B) Factorisation
C) Fractionation
D) Expansion
Feedback: Estimation is making a guess of nearly correct calculations, distances, prices, or capacities without precise calculations.

### Q2 [single-choice]
Stem: What is the basic unit of length (distance) in the metric system?
A) Metre (correct)
B) Kilogram
C) Litre
D) Second
Feedback: The metric system uses multiples of ten, with the metre as the basic unit of length.

### Q3 [single-choice]
Stem: Express $12\text{ km}$ in metres:
A) $12,000\text{ m}$ (correct)
B) $1,200\text{ m}$
C) $120\text{ m}$
D) $12\text{ m}$
Feedback: Since $1\text{ km} = 1000\text{ m}$, $12\text{ km} = 12 \times 1000 = 12,000\text{ m}$.

### Q4 [single-choice]
Stem: How many cubic centimetres ($\text{cm}^3$) make one litre?
A) $1,000\text{ cm}^3$ (correct)
B) $100\text{ cm}^3$
C) $10\text{ cm}^3$
D) $10,000\text{ cm}^3$
Feedback: The unit of capacity is the Litre (L), which is equal to one cubic decimetre ($1000\text{ cm}^3 = 1\text{ litre}$).

### Q5 [single-choice]
Stem: What number system does time measurement follow, unlike the base-ten metric system?
A) Sexagesimal system (base 60) (correct)
B) Binary system (base 2)
C) Denary system (base 10)
D) Octal system (base 8)
Feedback: Time follows the sexagesimal system (base 60) of the ancient Babylonian number system.

### Q6 [single-choice]
Stem: How many seconds are in $5\text{ minutes } 45\text{ seconds}$?
A) 345 seconds (correct)
B) 300 seconds
C) 445 seconds
D) 545 seconds
Feedback: $(5 \times 60) + 45 = 300 + 45 = 345\text{ seconds}$.

### Q7 [single-choice]
Stem: What is the rule for rounding up the last digit to be kept in an approximation?
A) The first digit to be ignored must be 5 or greater (correct)
B) The digit to be ignored must be strictly less than 4
C) The digit to be kept must be an even number
D) The number must be a prime number
Feedback: If the first digit to be ignored is 5 or more, the last digit kept is increased by 1.

### Q8 [single-choice]
Stem: Round off 48,057 to the nearest hundred:
A) 48,100 (correct)
B) 48,000
C) 48,060
D) 49,000
Feedback: The hundreds digit is 0, followed by 5; rounding up gives 48,100.

### Q9 [single-choice]
Stem: Round off 29,042 to 2 significant figures:
A) 29,000 (correct)
B) 29,040
C) 30,000
D) 29.00
Feedback: The first two significant figures are 2 and 9; the third digit is 0 ($< 5$), so it rounds down to 29,000.

### Q10 [single-choice]
Stem: Estimate the value of $63 \times 47$ by rounding each number to 1 significant figure:
A) 3,000 (correct)
B) 2,800
C) 2,400
D) 3,500
Feedback: $60 \times 50 = 3,000$.

### Q11 [single-choice]
Stem: Round off 253,718 to the nearest thousand:
A) 254,000 (correct)
B) 253,000
C) 250,000
D) 254,700
Feedback: The thousands digit is 3, followed by 7 ($7 \ge 5$), so 3 rounds up to 4, giving 254,000.

### Q12 [single-choice]
Stem: A school library receives 580 new books, and each shelf holds about 28 books. Approximately how many additional shelves are needed?
A) 20 shelves (correct)
B) 10 shelves
C) 30 shelves
D) 50 shelves
Feedback: $580 \approx 600$ and $28 \approx 30$; $600 \div 30 = 20\text{ shelves}$.

### Q13 [single-choice]
Stem: Which sector uses approximation as a primary tool when preparing annual budgets?
A) Government ministries (correct)
B) Art museums
C) Sports stadiums
D) Taxi parks
Feedback: Governments use approximation as a tool in preparing national budgets.

### Q14 [single-choice]
Stem: Which two digits are the only symbols used in the binary (Base 2) number system?
A) 0 and 1 (correct)
B) 1 and 2
C) 0 and 2
D) 1 and 10
Feedback: The binary system uses only two digits: 0 and 1.

### Q15 [single-choice]
Stem: In Base 2 numerals, what is the result of $1 + 1$?
A) $10_2$ (correct)
B) $2_2$
C) $11_2$
D) $0_2$
Feedback: In Base 2, $1 + 1 = 10_2$ (write 0 and carry 1).

### Q16 [single-choice]
Stem: Calculate the binary sum of $10_2 + 11_2$:
A) $101_2$ (correct)
B) $111_2$
C) $110_2$
D) $100_2$
Feedback: $10_2 + 11_2 = 101_2$ ($2 + 3 = 5_{10}$).

### Q17 [single-choice]
Stem: Calculate $11_2 + 11_2$ in Base 2:
A) $110_2$ (correct)
B) $100_2$
C) $101_2$
D) $111_2$
Feedback: $11_2 + 11_2 = 110_2$ ($3 + 3 = 6_{10}$).

### Q18 [single-choice]
Stem: What is the decimal (Base 10) value of the binary number $100_2$?
A) 4 (correct)
B) 2
C) 8
D) 100
Feedback: $100_2 = (1 \times 4) + (0 \times 2) + (0 \times 1) = 4_{10}$.

### Q19 [matching]
Stem: Match each measurement with its standard conversion equivalent:
Pairs:
- 1 kilometre -> 1000 metres
- 1 tonne -> 1000 kilograms
- 1 cubic metre -> 1000 litres
Feedback: $1\text{ km} = 1000\text{ m}$, $1\text{ t} = 1000\text{ kg}$, and $1\text{ m}^3 = 1000\text{ l}$.

### Q20 [matching]
Stem: Match each binary addition problem with its correct sum:
Pairs:
- $10_2 + 01_2$ -> $11_2$
- $10_2 + 10_2$ -> $100_2$
- $101_2 + 111_2$ -> $1100_2$
Feedback: $10_2 + 01_2 = 11_2$, $10_2 + 10_2 = 100_2$, and $101_2 + 111_2 = 1100_2$.
