Why This Matters to You

Have you ever played a guessing game where someone says, "I am thinking of a secret number; when I add 7 to it, the answer is 12"? In your head, you immediately deduce that the hidden number must be 5. In mathematics, instead of drawing question marks or empty boxes, we use letters of the alphabet called variables to represent these hidden numbers. This is the foundation of algebra: turning everyday riddles into clear, solvable mathematical sentences!

Key Terms

Mathematical Sentence A complete mathematical statement made up of numbers, operational signs ($+, -, \times, \div$), and symbols that make an assertion[cite: 2].
Variable A letter or symbol (such as $x, y, a,$ or $\Box$) used to represent an unknown or changing number in a mathematical statement[cite: 2].
Open Sentence A mathematical statement containing one or more unknown symbols whose truth cannot be decided until specific values are substituted[cite: 2].
Closed Sentence A mathematical statement containing no unknown variables that can be declared completely true or completely false immediately.
Substitution The process of replacing letters or symbols in an algebraic expression with given numerical values to calculate a result[cite: 2].

Core Concept

What is a Mathematical Sentence and an Open Sentence?

A mathematical sentence consists of numbers and symbols (representing unknown numbers) called variables. Consider the question: What number added to 7 will give you 12?

In mathematics, we can represent the unknown number using an empty box ($\Box$) or a letter ($x$):

$$\Box + 7 = 12 \quad \text{or} \quad x + 7 = 12$$

We call this statement an open sentence. It is called "open" because any number can be placed into the box, but usually only one unique value makes the sentence true.

If we put $5$ into the box: $5 + 7 = 12$ (This makes the sentence True).
If we put $4$ into the box: $4 + 7 = 11 \ne 12$ (This makes the sentence False).

Letters Representing Unknown Symbols

In advanced mathematics, we replace boxes ($\Box$) with letters of the alphabet ($a, b, c, x, y, z, p, q$):

In $14 + \Box = 17$, the statement becomes true when $3$ replaces the box ($14 + 3 = 17$).
In $h - 4 = 20$, the value of $h$ that makes the sentence true is $24$, because $24 - 4 = 20$.
In $z - 6 = 2$, the value of $z$ that makes the sentence true is $8$, because $8 - 6 = 2$.
In $g + g = 30$, adding two identical numbers gives $30$; therefore, $g = 15$ because $15 + 15 = 30$.
Solving Open Sentences by Finding the Value that Restores Mathematical Balance

Open Sentences with Two Unknowns (Substitution)

Sometimes a mathematical expression or sentence contains two or more unknown letters. When the numerical values of the letters are provided, we evaluate the expression by substitution (replacing each letter with its given number).

For example, if $x = 5$ and $y = 3$:

To find $x + y$: substitute $5$ for $x$ and $3$ for $y$:

$$x + y = 5 + 3 = 8$$

To find $2x - y$: multiply $2 \times 5$ and subtract $3$:

$$2(5) - 3 = 10 - 3 = 7$$

If $a = 15$ and $b = 6$:

$$a + b = 15 + 6 = 21 \quad \text{and} \quad a - b = 15 - 6 = 9$$

Comparing Sentence Types and Algebraic Roles

Completeness

Open Sentence vs Closed Sentence

An open sentence contains unknown variables and cannot be judged true or false until solved[cite: 2], whereas a closed sentence contains only known numbers and can be judged true or false immediately (e.g., $4 + 3 = 7$).

Algebraic Role

Constant vs Variable

A constant is a fixed number that never changes value (like $7$ or $12$)[cite: 2], while a variable is a letter ($x, y$) that represents an unknown or changing value[cite: 2].

Variable Multiplicity

Single Unknown vs Two Unknowns

A single-variable open sentence has one unique solution (e.g., $x + 7 = 12 \implies x = 5$)[cite: 2], while an expression with two unknowns requires values for both variables to be evaluated (e.g., $x + y$ when $x = 5, y = 3$)[cite: 2].

Common Mistakes to Avoid

Common Mistake

Assuming that a letter in algebra can take any random number and still keep the sentence true.

Scientific Fact

While any number can be substituted into an open sentence, only the correct specific value makes the sentence mathematically true[cite: 2].

Common Mistake

Adding the letter itself as a number (e.g., thinking $x + 5 = 5x$).

Scientific Fact

A letter represents an unknown quantity, so $x + 5$ cannot be merged into $5x$; $5x$ means $5 \times x$, while $x + 5$ represents addition.
