Week 06: Numbers in Base 2 — Binary Subtraction and Multiplication

Foundational curriculum module in Mathematics covering Numbers in Base 2 — Binary Subtraction and Multiplication for JSS 1.

Why This Matters to You

When digital computers calculate differences or scale up quantities, they do not borrow tens or recite decimal times tables like $7 \times 8 = 56$. Instead, microprocessors perform subtraction and multiplication using only zeros and ones, swapping bits and shifting electrical pulses. Mastering binary subtraction and multiplication unlocks the computational logic that powers software graphics, cryptography, and digital calculators.

Key Terms

Binary Subtraction The mathematical process of taking one base 2 numeral away from another using place value borrowing where $1\text{ two} = 10_2$[cite: 2].
Borrowing in Base 2 Taking a value of 1 from a higher column on the left, which becomes a value of 2 (written as $10_2$) in the column receiving it[cite: 2].
Binary Multiplication The repeated addition of binary numbers governed by the truth conditions $0 \times 0 = 0$, $1 \times 0 = 0$, $0 \times 1 = 0$, and $1 \times 1 = 1$[cite: 2].
Partial Product The intermediate binary numbers produced by multiplying the multiplicand by each individual bit of the multiplier before column addition[cite: 2].

Core Concept

Rules of Binary Subtraction

Binary subtraction follows four basic rules for single digits:

1.
$0 - 0 = \mathbf{0}$
2.
$1 - 0 = \mathbf{1}$
3.
$1 - 1 = \mathbf{0}$
4.
$10_2 - 1 = \mathbf{1}$ (when borrowing $1$ from the next higher column, that $1$ equals $2_{10}$, so $2 - 1 = 1$)

When subtracting column by column from right to left, if you need to subtract $1$ from $0$, you must borrow $1$ from the column immediately to the left. The borrowed $1$ enters the current column as $10_2$ (which equals decimal $2$). Therefore, $10_2 - 1 = 1$.

Fundamental Rules of Binary Subtraction and Long Multiplication

Rules of Binary Multiplication

Multiplication in Base 2 is simpler than in Base 10 because there are only four single-digit multiplication rules:

1.
$0 \times 0 = \mathbf{0}$
2.
$1 \times 0 = \mathbf{0}$
3.
$0 \times 1 = \mathbf{0}$
4.
$1 \times 1 = \mathbf{1}$

To multiply larger binary numerals, use long multiplication:

Multiply the top number by each bit of the bottom number from right to left.
Each row of partial products is shifted one place to the left, exactly like in base 10 arithmetic.
Finally, add all the partial products together using the binary addition rules ($1 + 1 = 10_2$).

Comparing Binary Subtraction and Multiplication Operations

Borrowing vs Carrying

Subtraction Borrowing vs Addition Carrying

Borrowing takes 1 from the left column to become 2 ($10_2$) in the lower column[cite: 2], while carrying moves a bundled 2 ($10_2$) upward to the next left column[cite: 2].

Operation Mechanics

Subtraction vs Multiplication

Subtraction removes values column by column using borrowing[cite: 2], whereas multiplication generates shifted copies of the top number that are summed using binary addition[cite: 2].

Multiplicative Outputs

Multiplication by 1 vs Multiplication by 0

Multiplying any binary string by 1 reproduces the exact string unchanged[cite: 2], whereas multiplying by 0 yields an entire row of zeros[cite: 2].

Common Mistakes to Avoid

Common Mistake

Treating a borrowed digit in binary subtraction as 10 (decimal ten).

Scientific Fact

Borrowing $1$ from a higher binary column yields $10_2$, which represents two ($2_{10}$), not ten[cite: 2].

Common Mistake

Forgetting to shift partial products one place to the left during long multiplication.

Scientific Fact

Each successive partial product must shift one column to the left to align with the correct binary place value ($1, 2, 4, 8, \dots$)[cite: 2].
